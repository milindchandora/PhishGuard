How a URL gives itself away

Feature extraction

Every URL is broken into ~27 numeric signals: length, character counts, subdomain depth, presence of an IP address, HTTPS usage, and known phishing vocabulary like "verify" or "secure-login".

Model scoring

Those signals are scaled and passed to a classifier trained on thousands of labeled legitimate and phishing URLs, which outputs a class and a confidence score.

Clear verdict

You get a plain answer — Safe or Phishing — with the confidence behind it, so you can decide before you click.

What PhishGuard checks

  • Domain & subdomain structure
  • Presence of an IP address instead of a domain
  • HTTPS usage
  • Suspicious brand-imitation keywords
  • URL shortening services
  • Unusual character density & entropy
  • @ symbols and redirect tricks
  • Query parameter counts
